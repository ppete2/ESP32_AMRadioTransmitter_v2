Bitluni's audio-to-header converter

  • Used to create audio header files for ESP32-projects "AM Radio Transmitter" by bitluni and "AM Radio Transmitter v2" by PPete
  • Project page: bitluni.net/am-radio-transmitter | Project video: youtu.be/lRXHd3HNzEo
  • Idea and original code by bitluni, sending him a warmly "High five"! Slighltly modified by PPete
  • "normalize": Audio's volume is increased to full volume
  • "resample": Audio's sample rate is changed. For AM transmission a smaller number, like 6000 Sa/s, is enough
